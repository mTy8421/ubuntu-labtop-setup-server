🚀 Complete Setup & Reference

Ubuntu Laptop Setup
for Home Server & Desktop

คู่มือการปรับแต่ง Ubuntu เมื่อนำเครื่องโน้ตบุ๊ก (Laptop) มาเปิดทิ้งไว้เป็น Home Server แบบปิดฝาพับ (Clamshell) หรือใช้งานสำหรับงาน Development อย่างมีประสิทธิภาพ

เริ่มตั้งค่า Server ตั้งค่า SSH Remote
1

การตั้งค่าระบบ Server บน Laptop

แก้ปัญหาเครื่องดับหรือตัดเข้าโหมด Sleep เมื่อปิดฝาพับ และตั้งค่าให้เหมาะกับเซิร์ฟเวอร์

1.1 ปิดฝาพับโน้ตบุ๊กไม่ให้เครื่องดับ/Sleep (Lid Close Settings)

/etc/systemd/logind.conf

เปิดไฟล์คอนฟิกของระบบจัดการล็อกอิน systemd-logind:

bash 
sudo nano /etc/systemd/logind.conf

ค้นหาและแก้ไข (หากมีเครื่องหมาย # อยู่ข้างหน้าให้นำออก) หรือเพิ่มบรรทัดเหล่านี้:

ini config 
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
📌 ข้อมูลเพิ่มเติม:

• ค่าดั้งเดิมของระบบคือ HandleLidSwitch=suspend

• การเปลี่ยนเป็น ignore จะทำให้ระบบทำงานต่อไปตามปกติเมื่อฝาพับถูกปิดลง

รีสตาร์ตเซอร์วิส systemd-logind เพื่อให้การตั้งค่ามีผล:

bash 
sudo systemctl restart systemd-logind.service
⚠️
ข้อควรระวัง: หากรันคำสั่งรีสตาร์ตนี้บนหน้าจอ Desktop Environment (GUI) เซสชันกราฟิกอาจรีโหลดและล็อกเอาต์ได้ หากเป็นไปได้แนะนำให้รันผ่าน SSH หรือเซฟไฟล์งานทั้งหมดก่อน

1.2 พักหน้าจออัตโนมัติเพื่อถนอมจอภาพ (Console Blanking)

/etc/default/grub

สำหรับเครื่องที่รันโหมด TTY/Console การเปิดหน้าจอทิ้งไว้อาจทำให้เกิดอาการจอเบิร์น (Screen Burn-in) และเปลืองพลังงาน สามารถตั้งให้จอดับอัตโนมัติได้เมื่อไม่มีการกดคีย์บอร์ด (เช่น 300 วินาที = 5 นาที)

bash 
sudo nano /etc/default/grub

แก้ไขหรือเพิ่มพารามิเตอร์ consoleblank=300:

grub config 
GRUB_CMDLINE_LINUX="consoleblank=300"
💡 หมายเหตุ: หากมีค่าเดิมอยู่แล้ว สามารถเว้นวรรคแล้วต่อท้ายได้ เช่น:
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash consoleblank=300"

อัปเดต GRUB และรีบูตเครื่องเพื่อใช้งาน:

bash 
sudo update-grub
sudo reboot

1.3 ปิดระบบ Sleep / Suspend โดยสิ้นเชิง (ทางเลือกเสริม)

systemctl mask

หากต้องการให้มั่นใจ 100% ว่าเครื่องจะไม่เข้าสู่ Sleep หรือ Hibernation ไม่ว่าจะเกิดเหตุการณ์ใด ให้ Mask service targets ของ systemd:

bash (Mask Sleep) 
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target

หากต้องการปลดล็อกกลับมาใช้งานโหมด Sleep ตามปกติในภายหลัง:

bash (Unmask Sleep) 
sudo systemctl unmask sleep.target suspend.target hibernate.target hybrid-sleep.target

1.4 ปิดโหมดประหยัดพลังงานของ Wi-Fi (Wi-Fi Power Saving)

NetworkManager

หากแล็ปท็อปเชื่อมต่ออินเทอร์เน็ตผ่าน Wi-Fi ตัวการ์ดอาจตัดเข้าโหมด Power Saving เมื่อไม่มีทราฟฟิก ส่งผลให้ SSH หลุดหรือไม่สามารถเชื่อมต่อเข้ามาได้:

bash 
sudo nano /etc/NetworkManager/conf.d/default-wifi-powersave-on.conf

เปลี่ยนค่าจาก 3 (เปิดโหมดประหยัดไฟ) เป็น 2 (ปิดโหมดประหยัดไฟ):

conf 
[connection]
wifi.powersave = 2

รีสตาร์ต NetworkManager:

bash 
sudo systemctl restart NetworkManager
2

การตั้งค่าการเชื่อมต่อระยะไกล (SSH Setup)

ติดตั้งเซอร์วิส OpenSSH ตรวจสอบ IP และเปิดพอร์ต Firewall ให้เชื่อมต่อได้จากภายนอก

2.1 ติดตั้งและเปิดใช้งาน OpenSSH Server

ติดตั้ง openssh-server และสั่งให้เริ่มทำงานอัตโนมัติตอนบูตระบบ:

bash 
sudo apt update
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
sudo systemctl status ssh

2.2 ตรวจสอบ IP Address และทดสอบการเชื่อมต่อ

ค้นหาหมายเลข IP Address บนเครือข่ายท้องถิ่น (LAN):

bash (บนเครื่อง Server) 
hostname -I

จากนั้นทดสอบเชื่อมต่อจากเครื่องคอมพิวเตอร์ของคุณ (Client):

ssh client 
ssh <username>@<server-ip>

2.3 การตั้งค่า Firewall (UFW)

อนุญาตให้ Port 22 (SSH) ส่งข้อมูลผ่านไฟร์วอลล์ได้ เพื่อไม่ให้ถูกบล็อกการเชื่อมต่อ:

bash 
sudo ufw allow ssh
sudo ufw enable
sudo ufw status
3

การตั้งค่าสำหรับ Ubuntu Desktop & Development

ติดตั้งชุดเครื่องมือจำเป็นสำหรับนักพัฒนา การสำรองข้อมูล และเครื่องมือตรวจสอบเซิร์ฟเวอร์

3.1 อัปเดตระบบ

อัปเดตแคชรายการแพ็กเกจและอัปเกรดซอฟต์แวร์ระบบให้เป็นเวอร์ชันล่าสุด:

bash 
sudo apt update && sudo apt upgrade -y

3.2 ติดตั้ง Timeshift สำหรับสำรองข้อมูล

Backup & Restore

Timeshift ทำหน้าที่คล้าย System Restore ใน Windows ช่วยถ่ายภาพสแนปชอตของระบบ (Snapshot) เผื่อในกรณีที่ติดตั้งแพ็กเกจหรือแก้คอนฟิกแล้วระบบพัง สามารถ Rollback กลับมาได้ทันที:

bash 
sudo apt install -y timeshift

3.3 ติดตั้งเครื่องมือและชุดพัฒนา (Development Tools)

Compiler & Utilities

รวมแพ็กเกจคอมไพเลอร์, ไลบรารีกราฟิก, เครื่องมือ CLI และภาษา Go:

bash 
sudo apt install -y \
  git \
  wget \
  curl \
  build-essential \
  make \
  cmake \
  gcc \
  clang \
  golang \
  fzf \
  libdrm-dev \
  libgtk-3-dev

3.4 แนะนำเครื่องมือมอนิเตอร์และบริหารระบบ (Monitoring & TUI)

เครื่องมือ TUI สำคัญที่ช่วยให้ดูแลและตรวจสอบทรัพยากรบนเซิร์ฟเวอร์ได้ง่ายขึ้น:

bash 
sudo apt install -y htop btop tmux net-tools
📊 btop / htop ใช้ดูการใช้ CPU, RAM, Network I/O, Disk usage และความร้อนของเซิร์ฟเวอร์แบบกราฟฟิกสวยงาม
🖥️ tmux รัน Terminal หลายหน้าต่างและคงเซสชันการทำงานไว้แม้ตัดการเชื่อมต่อ SSH เหมาะสำหรับรันบอท/เซิร์ฟเวอร์
